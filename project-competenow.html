Origin Story

Why I Built CompeteNow: The Personal Problem

In tech, diplomas, and software engineering, portfolio is everything and real-world project experience is paramount. Yet, finding suitable, high-calibre hackathons, case competitions, and innovation challenges was a frustrating, fragmented ordeal. Opportunities were scattered across random Discord servers, LinkedIn reposts, and student chat groups — meaning by the time I discovered great hackathons, registrations had often closed.

I created CompeteNow to permanently solve this pain point for myself and fellow ambitious student builders. By combining the hyper-intuitive swipe mechanics popularized by Tinder with Gemini AI-driven web scouting, students can effortlessly discover, evaluate, and save tailored hackathons in seconds.

Key Engineering & AI Contributions

Intuitive Tinder-Style Swipe Mechanics

Engineered smooth, gesture-friendly card interactions allowing users to swipe right to save hackathons, swipe left to pass, or bookmark competitions directly. Each card presents crucial decision points at a glance: prize pools ($100,000+), deadlines, team formats (1-4 members), and domain tags.

First-Ever Gemini API Implementation

Leveraged Google AI Studio and integrated Google Gemini API keys to power dynamic intelligent features. The AI model extracts key metadata, analyzes competition guidelines, and scours the web for newly announced hackathons to continually replenish the pipeline.

AI Radar & Autonomous Web Scouring

Implemented an active AI Radar scout alert system that automatically notifies users when fresh official competitions are detected, along with an on-demand AI web scouring engine that searches and verifies active application links in real-time.

Google Cloud Run Production Deployment

Containerized and deployed the complete web application onto Google Cloud Run in the asia-east1 region with zero cold-start bottlenecks, HTTPS encryption, custom responsive viewport support, and full cloud production uptime.

Saved Competitions & Pipeline Tracker

Engineered a dedicated Saved events manager where students can monitor saved deadlines, review team matching requirements, track external entry portals, and keep their competition calendar organized.

Preference & Skill Profile Tuning

Built fine-grained preference controls enabling students to filter by hackathon focus (AI/ML, Web3, FinTech, Sustainability, Design), location formats (In-Person vs. Virtual), and role specializations (Frontend, Backend, Data, Pitch).

Key Reflections & Milestones

  • First Production Web App: Moving from local localhost prototypes to deploying a live, publicly accessible web application on Google Cloud Run was a major developmental milestone that taught me cloud packaging, containerization, and environment variable security.
  • First AI Integration with Gemini: Working hands-on with Google AI Studio and Google Gemini API keys transformed my understanding of prompt engineering, model temperature tuning, and structuring unstructured web hackathon data into clean UI cards.
  • Solving a True Personal Need: Building a tool for a challenge I face daily fueled product intuition — every feature, from instant prize pool highlights to one-click saving, was designed from an authentic user-first perspective.
  • Next Steps: Future iterations will introduce AI-powered team matchmaking to pair solo hackers with teammates whose complementary skills match the competition criteria.
